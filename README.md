# SG DGF Janneby – Taktiktafel

Web-App der Mannschaft: Taktik (4-2-3-1 und 3-5-2 mit animierten Spielsituationen), Dehnprogramm, Spielerplus-Regeln und Strafenkatalog.

Live: https://julianptrsn.github.io/SGDGFSVJ/

Jeder Push auf `main` veröffentlicht die Seite automatisch über GitHub Actions.

## Installieren
- **Android:** Link öffnen → „Installieren“
- **iPhone:** Link in Safari öffnen → „Teilen“ → „Zum Home-Bildschirm“
